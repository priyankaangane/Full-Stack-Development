<br>

## 🏗️ Featured Projects

### 🎲 Dice Game
> A two-player dice-rolling game — every click rolls both dice in real time, updates the images on the page instantly, and declares a winner.

`Math.random()` · `querySelector()` · `setAttribute()` · Conditional Logic

---

### 🎮 Simon Game
> A memory/pattern game that plays a growing sequence of colours and sounds — repeat it correctly to advance, one wrong move and it's game over.

jQuery · Arrays · Event-Driven Design · Animations & Sound

## 📚 Learning Timeline

<details>
<summary><strong>Day 1–3 · Internet Fundamentals & HTML Basics</strong></summary>
<br>

How the internet actually works, client-server communication, HTML document structure, headings & paragraphs, lists & nesting, file paths, anchors & images, the HTML boilerplate, and deploying a static site with GitHub Pages.

**Built:** Movie Ranking · Birthday Invitation · Personal Portfolio

</details>

<details>
<summary><strong>Day 4–14 · CSS: Styling, Layout & Bootstrap</strong></summary>
<br>

Inline/internal/external CSS, selectors & specificity, the cascade, colour & typography, the box model, positioning (`static`/`relative`/`absolute`/`fixed`), Flexbox, CSS Grid, responsive design with media queries, and Bootstrap's grid & components. Plus core UI/UX principles — colour theory, typography, and attention design.

**Built:** Online Resume · Colour Vocab Website · Motivational Poster · CSS Flag · Web Design Agency Website · Pricing Table · Mondrian Painting · TinDog Startup Website

</details>

<details>
<summary><strong>Day 15–23 · JavaScript Fundamentals</strong></summary>
<br>

Data types & variables, string methods, arithmetic & the modulo operator, functions (parameters, arguments, return values), `Math.random()`, conditionals & logical operators, arrays, and `while`/`for` loops.

**Exercises:** Karel the Robot · Life in Weeks · BMI Calculator · Love Calculator · Leap Year Challenge · Who's Buying Lunch? · 99 Bottles of Beer · Fibonacci Generator

</details>

<details>
<summary><strong>Day 24–28 · DOM Manipulation & Advanced JavaScript</strong></summary>
<br>

The DOM as a tree, `querySelector`/`querySelectorAll`, styling via JS, `innerHTML` vs. `textContent`, event listeners & the `this` keyword, higher-order & callback functions, `switch` statements, object literals, constructor functions, keyboard events, and `setTimeout` animations.

**Built:** 🎲 Dice Game · Drum Kit

</details>

<details>
<summary><strong>Day 29–30 · jQuery</strong></summary>
<br>

Incorporating jQuery via CDN, `$()` selectors, `.css()`/`.addClass()`/`.removeClass()`, `.text()`/`.html()`/`.attr()`, jQuery event handling, and DOM/animation methods — all pulled together into one complete, event-driven game.

**Built:** 🎮 Simon Game

</details>

<br>
