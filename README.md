## 🎯 Boss-Level Game #1 — 🎲 Dice Game
**Showcase: DOM Manipulation & Intermediate JavaScript**

A two-player dice-rolling game where each click generates two random dice rolls, updates the corresponding dice images on the page in real time, and announces a winner.

**Concepts demonstrated:**
- `Math.random()` + `Math.floor()` to generate valid random dice values
- `document.querySelector()` to target specific elements
- `setAttribute()` to dynamically swap image sources based on the roll
- Conditional logic to compare rolls and declare a winner
- `window.onload` to run game logic automatically on page load

- Selecting and manipulating real elements on a live page, not just console output
- Why behaviour (JS), style (CSS), and structure (HTML) are deliberately kept separate

- Structuring multi-outcome logic cleanly using `switch` instead of nested `if`/`else`
- Modeling real-world entities using object literals and constructor functions

## 🎯 Boss-Level Game #2 — 🎮 Simon Game
**Showcase: Advanced JavaScript & jQuery**

A full memory/pattern-matching game: the game plays an increasingly long sequence of colours and sounds, the player must repeat it back exactly, and a single wrong move ends the game with a "game over" animation before it restarts.

**Concepts demonstrated:**
- Combining vanilla JS logic with jQuery for DOM manipulation and events
- Building and extending a growing game sequence (arrays) each round
- Comparing user input against the generated sequence in real time
- Chaining sounds and CSS animations together for feedback on every click
- Managing full game state: start, progress, win/continue, game-over, and restart
- Clean event-driven architecture — the entire game runs off user clicks/keypresses rather than a single linear script

## 💡 Key Concepts Learned

- How jQuery simplifies common DOM tasks compared to vanilla JavaScript — and where vanilla JS is still just as clear
- Structuring a real interactive game around state (not just a one-off script)
- Combining everything from earlier phases — DOM selection, events, arrays, conditionals, animations — into one cohesive, non-trivial project
- Debugging a multi-step interactive application, not just a single function
